## Quick Start

### 1. Install dependencies

```bash
pip install tensorflow>=2.13 scikit-learn matplotlib pillow seaborn numpy pandas tqdm imagehash
```

### 2. Download and prepare dataset

Follow the instructions in [DATASET_SETUP.md](DATASET_SETUP.md) to download the datasets,
then run:

```bash
python ml_model/prepare_dataset.py --raw-dir ml_model/data/raw --out-dir ml_model/data
```

### 3. Train the model

```bash
# Basic training (frozen backbone, 30 epochs max)
python ml_model/train.py

# With optional fine-tuning pass
python ml_model/train.py --fine-tune --epochs 20

# Custom options
python ml_model/train.py --data-dir ml_model/data --epochs 40 --batch-size 16 --learning-rate 5e-5
```

### 4. Evaluate the model

```bash
python ml_model/evaluate.py
```

Reports are saved to `ml_model/reports/`.

### 5. Generate simulated reports (before training — for integration testing)

```bash
pip install matplotlib scikit-learn numpy
python ml_model/generate_reports.py
```

## Model Contract (Summary for Member 2)

| Property          | Value                                      |
|-------------------|--------------------------------------------|
| Input shape       | `(1, 224, 224, 3)` — batch, H, W, RGB      |
| Normalization     | **centered** — `(pixel / 127.5) - 1.0`    |
| Input range       | `[-1.0, 1.0]` float32                      |
| Output            | Softmax probabilities, shape `(1, 3)`      |
| Class order       | `["Fresh", "Moderate", "Spoiled"]`         |
| Model format      | `.keras` (Keras v3 / TF 2.13+)             |

See [MODEL_USAGE.md](MODEL_USAGE.md) for full integration guide.
